How do we know software works? First, define the expected result. Then run the software and compare the actual result. A unit test checks one small rule, such as title validation. An integration test checks connected parts, such as the HTTP route and data store. An end-to-end test controls the real browser. It enters a task, selects Add task, and checks the visible result. The request moves through the user interface, backend, and store. An eval is different. It gives variable behavior a score. This project requires at least zero point nine. A smoke test runs after deployment and checks basic availability. In CI, unit and integration tests run first. Evals and browser tests run before deployment. The smoke test runs after deployment. Use all five checks because each one observes a different part of correctness.
